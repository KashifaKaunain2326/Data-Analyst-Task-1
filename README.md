# Data-Analyst-Task-1

Task 1: Data Cleaning and Preprocessing

📌 Project Overview

This project focuses on cleaning and preprocessing a raw dataset to improve data quality and prepare it for further analysis.

The main objective is to identify and handle missing values, duplicate records, inconsistent formats, and incorrect data types to create a clean and structured dataset.

🎯 Objectives

- Identify and handle missing values.
- Remove duplicate records.
- Standardize inconsistent text values.
- Convert date formats into a consistent format.
- Rename column headers for better readability.
- Correct inappropriate data types.
- Prepare the dataset for data analysis and visualization.

🛠️ Tools & Technologies

- Python
- Pandas
- Excel
- Jupyter Notebook

🔍 Data Cleaning Steps

1. Data Inspection

- Loaded the raw dataset.
- Checked the number of rows and columns.
- Examined column names and data types.
- Identified missing values and duplicate records.

2. Handling Missing Values

- Identified null values using "isnull()".
- Handled missing values using appropriate methods.

3. Removing Duplicates

- Identified duplicate records.
- Removed duplicate rows using "drop_duplicates()".

4. Standardizing Data

- Standardized text values.
- Removed unnecessary spaces.
- Converted text into a consistent format.

5. Date Format Correction

- Converted date columns into a consistent date format.

6. Renaming Columns

- Renamed column headers using lowercase letters and underscores.

7. Data Type Correction

- Checked and corrected data types.
- Converted numerical columns into appropriate numeric types.
- Converted date columns into datetime format.

📊 Project Deliverables

- Cleaned dataset (CSV format).
- Python code / Jupyter Notebook.
- Summary of data cleaning activities.

📈 Outcome


Successfully performed data cleaning and preprocessing to improve dataset quality, consistency, and accuracy.

The cleaned dataset is now ready for further data analysis and visualization.
